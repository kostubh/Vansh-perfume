# PUREN - Luxury Perfume E-Commerce Website (Web Version)

A stunning, interactive luxury perfume e-commerce website transitioning to a JavaScript and HTML-based implementation.

## Features

### Interactive Experiences
- **Scent Finder Quiz**: Personalized fragrance recommendations based on your personality and preferences
- **Custom Blend Creator**: Design your own perfume by selecting from premium fragrance notes
- **Fragrance Wheel**: Visual exploration of scent families
- **Mood & Moment Recommendations**: Find the perfect fragrance for any occasion

### Design Highlights
- Luxury gold and black color scheme
- Custom CSS with elegant typography (Playfair Display, Cormorant Garamond)
- Smooth animations and hover effects
- Responsive layout
- Professional logo design
