# PUREN - Luxury Perfume E-Commerce Website

A stunning, interactive luxury perfume e-commerce website built with Python and Streamlit.

## Features

### Interactive Experiences
- **Scent Finder Quiz**: Personalized fragrance recommendations based on your personality and preferences
- **Custom Blend Creator**: Design your own perfume by selecting from premium fragrance notes
- **Fragrance Wheel**: Visual exploration of scent families
- **Mood & Moment Recommendations**: Find the perfect fragrance for any occasion
- **Interactive Visualizations**:
  - Fragrance pyramids showing top, middle, and base notes
  - Scent evolution timeline
  - Mood radar charts
  - Animated note transitions

### Shopping Features
- Product catalog with 8 signature fragrances
- Advanced filtering (category, season, price, intensity)
- Detailed product pages with visualizations
- Favorites/wishlist functionality
- Session-based cart management

### Design Highlights
- Luxury gold and black color scheme
- Custom CSS with elegant typography (Playfair Display, Cormorant Garamond)
- Smooth animations and hover effects
- Responsive layout
- Professional logo design

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run app.py
```

3. Open your browser to `http://localhost:8501`

## Deployment to Streamlit Cloud

1. Push this repository to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Deploy from your GitHub repository
4. The app will automatically use `requirements.txt`
